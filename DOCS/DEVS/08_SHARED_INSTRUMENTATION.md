# Shared Instrumentation - Statistics and Recently Added Instruments

This doc covers the two boxes at the top of the Instrument Finder page (/shared-instrumentation/instrument-finder):
- "Statistics" - the number of facilities and the number of instruments.
- "Recently Added Instruments" - links to the newest Instrument nodes.

This doc will grow as more of the Shared Instrumentation section gets built out.  For the Instrument Finder page itself, see 03_FINDER_MODULE.md.

## What they are

They are normal Drupal Views, so they update automatically as content is added or removed. There are three of them (find them at Manage >> Structure >> Views):

| View (machine name)  | What it does                                     |
|----------------------|--------------------------------------------------|
| facilities_count     | Counts published 'Facility or Lab' nodes         |
| instruments_count    | Counts published 'Instrument' nodes              |
| rec                  | Lists the most recently added 'Instrument' nodes |

Even though "Statistics" looks like one box, it is really TWO views (facilities_count and instruments_count) glued together with CSS.

## How the count views work (aggregation)

A normal view lists nodes one by one. To make a view output a single number instead, the two count views use aggregation:
- In the view, under Advanced, "Use aggregation" is set to Yes.
- The field is then set to aggregate with COUNT, so instead of listing every node, the view counts them and prints the total.
- The filter on the view (content type = Instrument or Facility or Lab, published only) decides WHAT gets counted.

The rec view doesn't use aggregation. It is just a normal list of Instrument nodes, sorted newest first, limited to a few items ("Items per page" setting).

## Editing them

All normal edits happen in the Drupal Views UI - header text, number of recent items, filters, etc.  Edit the "block_1" display of each view, since that is the one the finder page uses.  Changes show up on the page as soon as you save.

## How they get onto the finder page

The finder page is generated by our custom module, not a normal Drupal page, so the views can't be dropped onto it as blocks. Instead the module embeds them in code:
- The controller (web/modules/custom/finders/instrument_finder/src/Controller/InstrumentFinderController.php, content() function) embeds the three views and hands them to the template.
- The template (templates/instrument_finder.html.twig) prints them at the top of the page.
- If a view is deleted or broken, the page still renders - it just skips that box.

## Styling

The card look comes from CSS at the bottom of css/instrument_finder.css (section commented "Instrument Finder additions"). Each view has CSS classes set in its view settings that the CSS targets - including statistics-card-top / statistics-card-bottom, which are what glue the two count views into one Statistics card. If you rename a class in the view settings, update the CSS to match.
